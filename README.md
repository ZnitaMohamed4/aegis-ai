# Aegis AI — Monorepo

This repository is organised as a monorepo with the following top-level directories:

```
aegis/
├── aegis-frontend/        Angular dashboard (UI)
├── aegis-backend/         Django API + webhook receivers
├── aegis-ml/              M1/M2 ML models
└── evolution-api/         (to be added)
```
